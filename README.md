# Seltec · Faturas e Permutas

Plataforma interna da Seltec Energia Solar para controle das faturas de energia injetada e das permutas.

- O código fica aqui; **os dados ficam no Supabase**, protegidos por login (só usuários cadastrados acessam).
- `supabase.sql` cria a tabela, as regras de acesso e a pasta de arquivos.
- Publicado pelo GitHub Pages.
